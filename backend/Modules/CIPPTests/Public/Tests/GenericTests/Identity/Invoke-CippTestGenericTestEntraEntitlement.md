# Entra ID P1/P2 Seats Cover Conditional Access Scope

Conditional Access needs Microsoft Entra ID P1, and risk-based policies (sign-in risk and user risk) need Microsoft Entra ID P2. This test compares the seats a tenant owns, counted by service plan, with the enabled member users in scope of enforced policies. Guests are billed on monthly active users and are not counted. Users in scope with no plan assigned are advisory evidence for a true-up.

**Remediation action**
- [Conditional Access license requirements](https://learn.microsoft.com/en-us/entra/identity/conditional-access/overview#license-requirements)
- [Microsoft Entra licensing](https://learn.microsoft.com/en-us/entra/fundamentals/licensing)
- [External ID pricing for guests](https://learn.microsoft.com/en-us/entra/external-id/external-identities-pricing)
