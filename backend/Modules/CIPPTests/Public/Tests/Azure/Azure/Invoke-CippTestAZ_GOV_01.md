This initiative is the policy set behind Defender for Cloud's recommendations. Without it, Defender's free posture assessment has little to report.

**Frameworks** (indicative)

- Themes: Secure configuration baseline and posture assessment
- MCSB: PV-1, PV-2
- CIS Controls v8: 4.1
- NIST CSF 2.0: PR.PS, ID.RA
- NIST 800-53: CM-6, RA-5
- CMMC / 800-171: CM.L2-3.4.2, RA.L2-3.11.2
- SOC 2: CC7.1
- ISO 27001: 8.8, 8.9

**Remediation Action**

1. Activating Defender for Cloud normally assigns it as "ASC Default". Otherwise: Policy → Assign initiative → "Microsoft cloud security benchmark".
