Defender for Servers adds endpoint detection (Defender for Endpoint), vulnerability assessment and just-in-time VM access for Azure VMs. Only subscriptions that contain matching resources are evaluated.

**Remediation Action**

1. Defender for Cloud → Environment settings → select the subscription → Defender plans → turn on Defender for Servers.
2. This is a paid plan; review pricing with the client before enabling.
