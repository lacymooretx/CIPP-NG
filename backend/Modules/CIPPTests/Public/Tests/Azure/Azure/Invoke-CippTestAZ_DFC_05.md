Defender for SQL detects SQL injection, anomalous access and brute force, and runs vulnerability assessment on Azure SQL. Only subscriptions that contain matching resources are evaluated.

**Remediation Action**

1. Defender for Cloud → Environment settings → select the subscription → Defender plans → turn on Defender for Azure SQL.
2. This is a paid plan; review pricing with the client before enabling.
