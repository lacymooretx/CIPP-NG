An immutable vault blocks operations that would shorten retention or delete recovery points early.

**Frameworks** (indicative)

- Themes: Protection of backup data
- MCSB: BR-2
- CIS Controls v8: 11.3
- NIST CSF 2.0: PR.DS
- NIST 800-53: CP-9
- CMMC / 800-171: MP.L2-3.8.9
- SOC 2: A1.2
- ISO 27001: 8.13

**Remediation Action**

1. Vault → Properties → Immutable vault → Enable (Locked makes it irreversible).
