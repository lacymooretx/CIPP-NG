Network Watcher provides connection troubleshooting, packet capture and flow logs for a region.

**Frameworks** (indicative)

- Themes: Network traffic logging
- MCSB: LT-4
- CIS Controls v8: 13.6
- NIST CSF 2.0: DE.CM
- NIST 800-53: AU-12, SI-4
- CMMC / 800-171: AU.L2-3.3.1
- SOC 2: CC7.2
- ISO 27001: 8.16

**Remediation Action**

1. It is created automatically when a VNet is created unless auto-enable was turned off. Create one in the listed region (resource group NetworkWatcherRG).
