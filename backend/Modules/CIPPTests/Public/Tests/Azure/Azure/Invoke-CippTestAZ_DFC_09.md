Defender for Cloud emails security alerts to the subscription's security contact. Without one, alerts only appear in the portal, where nobody may be looking.

**Remediation Action**

1. Defender for Cloud → Environment settings → subscription → Email notifications.
2. Add an MSP security mailbox (or ticketing address) and save.

**Links**
- [Configure email notifications for alerts](https://learn.microsoft.com/en-us/azure/defender-for-cloud/configure-email-notifications)
