Defender for Resource Manager watches the management plane for suspicious operations such as mass deletion, privilege changes and known attacker toolkits.

**Remediation Action**

1. Defender for Cloud → Environment settings → select the subscription → Defender plans → turn on Defender for Resource Manager.
2. This is a paid plan; review pricing with the client before enabling.
