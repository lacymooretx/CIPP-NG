With the integration on, Defender for Servers deploys Microsoft Defender for Endpoint to VMs automatically. Only subscriptions with VMs are evaluated.

**Frameworks** (indicative)

- Themes: Threat detection and endpoint protection
- MCSB: LT-1, ES-1
- CIS Controls v8: 10.1, 13.1
- NIST CSF 2.0: DE.CM
- NIST 800-53: SI-3, SI-4
- CMMC / 800-171: SI.L1-3.14.2, SI.L2-3.14.6
- SOC 2: CC6.8, CC7.2
- ISO 27001: 8.7, 8.16

**Remediation Action**

1. Defender for Cloud → Environment settings → subscription → Integrations → enable "Allow Microsoft Defender for Endpoint to access my data".
