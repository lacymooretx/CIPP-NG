# What's New (Aspendora)

Lists the features this CIPP adds on top of upstream CyberDrain CIPP, newest first, grouped by month. Upstream changes are under **View release notes** in the account menu.

* Search by name, description, area or ticket number, or filter by area.
* Each entry links to the page where the feature lives, when it has one.
* **New** marks entries added since you last opened the page. The account menu shows a green dot on **What's New (Aspendora)** until you have seen the newest entry. The last-seen date is kept in your browser.

The content comes from `frontend/src/data/aspendora-whats-new.json`. Every new fork feature adds an entry there in the same change; see `docs/aspendora-whats-new.md` in the repository.
